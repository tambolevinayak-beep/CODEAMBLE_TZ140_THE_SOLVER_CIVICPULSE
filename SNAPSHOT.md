## 🏗️ Technical Stack (Baseline)
- **Frontend**: React (v19), Vite
- **Backend / Database / Auth**: Supabase
- **Maps & Charts**: Leaflet (react-leaflet), Recharts
- **Animations / Styling**: Framer Motion, Lucide React

## 🤖 AI Usage Disclosure
This project was initially built for the Round 1 evaluation of CODEAMBLE 2026 with the assistance of AI tools. 
- **AI Tool Used**: Gemini 3.1 Pro
- **What AI helped with**:
  - Scaffolding the React + Vite frontend components
  - Integrating Supabase Auth and Database queries
  - Designing UI layouts (Citizen Layout, Admin Dashboard, Issue Detail)
  - Generating initial project structure and baseline configuration

*Note: All team members are fully aware of the underlying implementation and can explain the AI-assisted code during judging.*

## ✅ Features Already Built (Pre-Hackathon Baseline)
The following features are included in this initial baseline commit and were built prior to the 24-hour hackathon period:
- User registration and login via Supabase Auth
- Problem submission form (category, description, location, photo upload)
- Government authority / Admin dashboard (AdminDashboard.jsx)
- Problem status tracking and detail view (IssueDetail.jsx)
- Citizen dashboard layout (CitizenLayout.jsx)
- Social reels feed for civic issues (ReelsFeed.jsx)
- Initial onboarding survey (OnboardingSurvey.jsx)

## 🚀 What We Plan to Build in Round 2
During this 24-hour hackathon, we will be building the following new features on top of this baseline:
1. **AI-powered priority scoring**: Automatically assigning severity scores to problems based on descriptions and images.
2. **Real-time SMS/email notifications**: Alerting users when their reported issues are updated.
3. **Multi-language support**: Localizing the app for Hindi and Marathi speakers.
4. **Advanced Geolocation mapping**: Creating interactive heatmaps of reported issues using Leaflet.
5. **Government response time analytics**: Adding visual dashboards (via Recharts) to track authority performance.
